# Prathiba & Abhishek — wedding invitation

A small, responsive, static wedding invitation for GitHub Pages. It uses plain HTML, CSS and JavaScript, so it needs no build step or paid hosting.

## Publish on GitHub Pages

1. Create a GitHub repository and put `index.html`, `style.css`, and `script.js` in its root (or copy the contents of this folder to the root of an existing repository).
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub will show the public Pages address in that section after it publishes.

## Before publishing

- The year **2026** is inferred from the current date and should be confirmed. If needed, update the date shown in `index.html` and `weddingDate` in `script.js` together.
- The shared Google Maps links are used directly as venue directions buttons. Open both links once to confirm they lead to the intended venues before sharing.
- Google Fonts load from Google. The invitation content itself is hosted as static files on GitHub Pages.
